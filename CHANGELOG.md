# Changelog

All notable changes to MyUI Design System will be documented in this file.

## [1.0.0-beta.1] - 2025-11-10

### 🎉 Initial Beta Release

#### Added
- **25+ UI Components** built on shadcn/ui foundation
  - Core Elements: Button, Input, Textarea, Switch, Checkbox, Radio, Select, Slider
  - Structural Elements: Card, Dialog, Drawer, Sheet, Tooltip, Popover, Accordion
  - Navigation: Navbar, Breadcrumb, Tabs, Pagination, Command, Dock

- **Quintet Color Palette**
  - Obsidian (#1a1a1a) - Main backgrounds
  - Ember (#b45f3a) - Copper accents, active states
  - Wine Dusk (#3c2a3d) - Velvet containers, depth
  - Glass (#4a9c9b) - Aqua accents (legacy)
  - FineShyt (#f4dce0) - Premium matte pink text

- **Design Features**
  - Dark, mysterious aesthetic with minimal design
  - 300-500ms ceremonial animations throughout
  - No drop shadows - color separation via Wine Dusk
  - Lowercase headings with JetBrains Mono font
  - Consistent Wine Dusk/Ember color scheme

- **Component Enhancements**
  - TypeScript interfaces for all components
  - Enhanced Button with loading states, left/right icons
  - Enhanced Input with error states, icon support, validation
  - Card variants (default, outlined, elevated)
  - Dock component with macOS-style magnification (Framer Motion)

- **Showcase Pages**
  - Landing page with Quintet palette display
  - Core Elements showcase with professional examples
  - Structural Elements (Containers) showcase
  - Navigation Elements showcase with interactive Dock demo

- **Documentation**
  - Comprehensive README with all component examples
  - Quick start guides for common use cases
  - Design principles and color usage guidelines
  - Tech stack documentation

#### Tech Stack
- Next.js 16 with App Router
- Tailwind CSS v4 (inline @theme format)
- TypeScript 5
- Framer Motion for animations
- Radix UI primitives
- Lucide Icons

#### Design Philosophy
- Mysterious, elegant, intentional
- Slow, smooth animations (300-500ms)
- Color separation over drop shadows
- Minimal with generous negative space
- Lowercase aesthetic
